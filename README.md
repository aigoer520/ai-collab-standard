# AI 协作对齐规程

**Alignment Protocol for AI Collaboration · v1.0（草案）**

一套让 AI 助手按固定规矩长期协作的规程：先对齐再动手、不许编造、回答有格式、改动不漏项。别的用户拿到后，按安装说明把核心层粘贴到自己的 AI 助手，即可生效。

## 解决什么问题

一是助手抢跑——没对齐就动手，返工连连。

二是助手编造——不知道也敢报数字、报出处。

三是回答混乱——没结论、没分条、重点不突出。

四是改动漏项——说一处改一处，其他该改的没跟上。

## 快速开始（三步）

第一步，打开 STANDARD.md，复制「核心层」全文。

第二步，粘贴到你的助手的长期指令区（记忆文件、自定义指令或 AGENTS.md，任选其一；细则见正本的安装说明）。

第三步，发一句「复述总则」验证，再用正本里的 3 句测试话术验收：试它会不会抢跑、会不会编数字、排版合不合格。

## 核心层速览

1. 先对齐，后执行
2. 不许推断
3. 回答格式与要求
4. 收尾调整机制
5. 交叉印证
6. 完成前验证
7. 冲突优先级
